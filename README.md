# LATENT

### You were never just scrolling.

LATENT is an interactive experiment that explores how algorithms can learn from seemingly insignificant human behavior — a pause, a click, a skip, a moment of hesitation — and use those signals to shape what we see next.

Instead of explaining algorithmic personalization from the outside, LATENT puts the user inside the loop.

You scroll.
You choose.
The system observes.
The feed adapts.
A profile emerges.

And eventually, the interface shows you what it learned.

## The idea

Most people experience recommendation systems as a feed.

LATENT asks you to look at the other side of that feed:

> **What does the system learn about you while you are using it?**

A user is presented with content and makes natural choices throughout the experience.

Those choices become signals.

Signals influence a behavioral model.

The model influences the next experience.

This creates a feedback loop:
